# audio/Lektion1 – BLCUP Lesson Tracks (Lektion 1)

17 BLCUP native textbook recordings (Neues Praktisches Chinesisch, Book 1, Lektion 1).

IMPORTANT: These are full lesson audio tracks (dialogues, phonetics exercises, classroom phrases, intros) – NOT single-word card audio. Do NOT link them with `[sound:]` in `cards.tsv`. Card audio lives in `audio/Elevenlabs/Lektion1/` (single words).

Naming: `NN_dialogue_<description>.mp3` – NN = track number from the original BLCUP file (`XSHYGT-F-01-NN.mp3`), e.g. `15_dialogue_ni_he_shenme_what_do_you_drink.mp3` (NOT `15_ma.mp3` – the track says "你喝什么? 来一杯茶。").

Note: Tracks 04 and 08 (classroom phrases) could not be transcribed reliably by automatic speech recognition – names are best-effort, please spot-listen to confirm.
