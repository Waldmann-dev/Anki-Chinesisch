# 00. Phonetic Foundation Course

Deck: `Chinese::00. Phonetic Foundation Course`

Source: Neues Praktisches Chinesisch (3rd ed.), Book 1, Lesson 1 – Phonetics + Characters/Strokes handouts. No exercises.

Format: Q&A knowledge recall, in English.
`cards.tsv` columns: Question | Answer | Example

Card schema (user rule): only structural questions – What are...? What is...? What is the rule...? Which vowel...? No general knowledge (e.g. how many people speak Chinese), no translation quiz (What does X mean?), no stroke-count trivia for a single character, no yes/no "is neutral the 5th tone?".
Each card is short and concise. Import in Anki: File > Import, separator Tab.
